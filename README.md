
# Calculator App

A functional calculator built using **vanilla JavaScript**, HTML, and CSS — no frameworks or libraries used. Built as part of my JavaScript learning journey to practice DOM manipulation, event handling, and error handling.

## 🔗 Live Demo
[Click here to try it out](https://subhashree-ui.github.io/Calculator-app/calculator.html)

## ✨ Features
- Perform basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear button to reset the display
- Error handling for invalid calculations (e.g., incomplete expressions)
- Custom dark-themed UI with hover and active button effects

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (ES6)

## 📚 Concepts Practiced
- DOM manipulation (`querySelectorAll`, `getAttribute`)
- Event listeners and event handling (`addEventListener`, `forEach`)
- Using `data-*` attributes to store button values
- `eval()` for dynamic expression evaluation
- `try-catch` for error handling
- CSS Grid for button layout

## 🚀 How to Run
1. Clone or download this repository
2. Open `calculator.html` in any browser
3. Start calculating!

## 📖 What I Learned
This project helped me understand how to handle multiple interactive elements at once using `querySelectorAll` and `forEach`, rather than selecting each button individually. I also learned the importance of error handling — using `try-catch` to prevent the app from crashing when an invalid calculation is attempted, and debugged several real issues including mismatched HTML/CSS class names and incorrect event listener names.
